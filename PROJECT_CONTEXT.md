## 2. Поточний стек та інфраструктура

* **Фронтенд:** Vanilla JavaScript (ES-модулі), HTML5, CSS3, Google Model Viewer (3D глобус WebGL).
* **Бекенд та база даних:** Firebase Auth (Google Sign-In) + Cloud Firestore (проєкт `hhhh-c5f0a`).
* **Локальний веб-сервер:** `node server.js` на порті **8080** (`http://localhost:8080/`).
* **Тестування:** Вбудований тестовий раннер `node:test` (`npm test`).  
  **Покриття:** **160 з 160 тестів проходять успішно (100%)**.

## 4. Що вже повністю реалізовано (100% готовність)

1. **Демо-режим для журі МАН**:
   - Член журі або гість заходить без паролів та реєстрації.
   - Відкрито: «Про проєкт», 3D глобус, аркадну гру «Козацький Шлях», Стадію 1 Рівень 1.
   - Захищено: сторінка налаштувань закрита матовим оверлеєм із поясненням про хмарну синхронізацію Firestore; на рівнях 2–4 та босі стоїть демо-замок.
   - Після проходження 1-го рівня з'являється інтерактивний блок із пропозицією зареєструватися через Google в 1 клік, після чого результат автоматично зберігається в базі.
   - У верхньому меню замість «Вийти» для гостя відображається золота кнопка «Увійти» та маркер «Демо».
2. **Аудіоплеєр та плейлист «Метал-підтримка»**:
   - Перейменовано плейлист №1 на честь світових рок-гуртів, які активно підтримали Україну (Metallica, Iron Maiden, Judas Priest, Megadeth, Black Sabbath / Ozzy Osbourne, Pink Floyd feat. Андрій Хливнюк).
   - Сумнівні або контроверсійні треки вилучено.
   - Працюють онлайн-радіопотоки (Radio ROKS HD, Хіт FM, Радіо Байрактар тощо).
3. **Бігуча стрічка цитат**:
   - 15 висловів: 10 українських гетьманів + 5 прямих цитат рок-легенд із зазначенням імен та гуртів.
   - Працює на всіх сторінках сайту з плавною анімацією 72с та паузою при наведенні.
4. **Режим «Козацька мова» (Січова говірка)**:
   - Повна динамічна локалізація через `core/cossack.js` за таблицею перекладу автора (шаблі, здобич, курінь, клейноди, супостати).
   - Миттєво перемикається в налаштуваннях та синхронізується з акаунтом у Firestore.
5. **Оптимізація 3D карти**:
   - Вимкнено важкі динамічні розрахунки тіней на кожній вершині меша (`shadow-intensity="0"`), видалено CSS `box-shadow` keyframe-анімації над WebGL, додано золотий брендовий прелоадер. Стабільні 60 FPS на будь-якому залізі.
6. **Стартова сторінка за замовчуванням**:
   - Замість налаштувань сайт одразу відкриває «Про науковий проєкт» ([about/about.html](about/about.html)).
